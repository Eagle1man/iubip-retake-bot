# iubip-retake-bot

MVP сервиса записи на пересдачу через бота MAX.

**Статус: в работе.** План исполнителя: `D:\itотдел\docs\plan-iubip-retake-bot-mvp.md`.
Заявка отдела: T-1074.

## Что это

Работающий сквозной сценарий «студент записывается → преподаватель видит → дирекция отмечает оплату → уведомления»,
демонстрируемый без токена MAX через встроенный mock-режим и веб-эмулятор чата.

## Как показать демо за 5 минут

> Раздел наполняется в Фазе 12 — после того, как e2e-тест пройдёт полный цикл.
> Инструкция пишется по проверенному пути, а не по замыслу.

```bash
docker compose up --build
curl http://localhost:3000/healthz   # {"db":"ok","redis":"ok","mockMax":true}
# открыть http://localhost:3000/mock/
```
